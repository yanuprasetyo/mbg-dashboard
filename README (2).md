# Dashboard Kasus MBG Indonesia

Dashboard interaktif untuk monitoring kasus-kasus terkait program **Makan Bergizi Gratis (MBG)** di Indonesia, meliputi keracunan makanan, penolakan, penutupan dapur, dan penetapan KLB.

## Fitur
- 🗺️ Peta interaktif dengan 248+ titik lokasi
- 🔍 Filter berdasarkan jenis peristiwa, provinsi, dan tahun
- 📊 Statistik ringkasan
- 📋 Daftar kasus yang dapat di-scroll dan dicari
- 📱 Responsif untuk mobile

## Deploy ke GitHub Pages

1. Upload semua file ke repository GitHub
2. Aktifkan GitHub Pages di Settings → Pages → pilih branch `main`, folder `/root`
3. Dashboard langsung bisa diakses di `https://username.github.io/nama-repo`

## Data
Data bersumber dari pemberitaan media lokal dan nasional, dikompilasi untuk transparansi dan evaluasi program MBG.
